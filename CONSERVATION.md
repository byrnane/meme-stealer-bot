# Meme Stealer Bot: состояние на 12 октября 2026

Проект законсервирован до возвращения к разработке; репозиторий переводится в архив.

Репозиторий: [byrnane/meme-stealer-bot](https://github.com/byrnane/meme-stealer-bot). Основная ветка: `main`. Исходный коммит перед консервацией: `1d9bd27939a9`.

## Назначение и состояние

Личный Telegram-бот для публикации мемов в канал. Версия исходников — 0.3.0; Python 3.12+, aiogram, long polling и SQLite. Принимает фото, GIF, видео и альбомы, убирает исходную подпись, добавляет комментарий и общую подпись, позволяет посмотреть превью или опубликовать сразу. Управление ограничено владельцем.

## Данные и ограничения

Для запуска нужны `.env` с учетными данными и отдельная SQLite-база. Они намеренно не публикуются. Клон исходников не возвращает настройки и состояние бота; сначала восстановите сохраненные локальные данные. Не запускайте одновременно две polling-копии одного бота.

Репозиторий сохраняется как завершенный прототип без обещания поддержки. Новая функциональная приемка Telegram и VPS при консервации не проводилась. Workflow `Deploy` отключен до публикации архивной документации, чтобы push не запускал развертывание. Существующие серверы не изменялись.

## Запуск и проверки

Windows:

```powershell
.\scripts\setup.ps1
# Восстановите свою .env и базу до запуска.
.\scripts\doctor.ps1
.\scripts\start.ps1
```

Проверки: `.\scripts\check.ps1`. Для Linux доступны соответствующие `.sh`-скрипты. Установка и развертывание описаны в [README.md](README.md) и [DEPLOY.md](DEPLOY.md).

## Возвращение

Снимите архивный статус, восстановите зависимости и рабочие данные, затем проверьте отправку на отдельном тестовом боте и канале. Workflow `Deploy` включайте отдельно, только после проверки сервера, GitHub Environment и секретов. Само снятие архива не является разрешением на деплой.
